# coverlet.MTP

用途は、テストが実行していない箇所を見つけるカバレッジ計測である。
採用は、C# は coverlet.MTP である。
判断基準は、採用済みのテスト実行系が載る実行基盤の拡張として動き、分岐ごとに到達した側と到達しなかった側を数え分けた機械可読な coverage report を出力し、記録した branch の下限を判定する検証入口の入力にできることである。
撤回条件は、判断基準を満たさなくなることであり、保守の停止、report 形式、到達しなかった側を数え分ける実装の変化、実行基盤の拡張としての統合方法の変化を再評価のトリガーとする。

## カバレッジ

### 要求
カバレッジは coverlet.MTP で計測し、分岐ごとに到達した側と到達しなかった側を数え分ける。
下限は、project が branch と line のそれぞれに記録する。
記録した下限は、cobertura 出力の `branches-covered` と `branches-valid` から検証入口で判定する。
カバーしない箇所の扱いと、数値を目標にしない扱いは、[structure/tests の methods](../../structure/tests/methods.md) に従う。

### 根拠
分岐の到達した側と到達しなかった側を数え分けなければ、片側だけを実行したテストが網羅として数えられる。
絶対数の `branches-covered` と `branches-valid` を読めば、行ごとの条件情報を再集計せずに下限を判定できる。

### 完了条件
カバレッジが coverlet.MTP で計測され、branch と line が数えられている。
project が、branch と line の下限を記録している。
記録した下限が、cobertura 出力の集計から検証入口で判定されている。

### 禁止事項
片側だけを実行した分岐を、網羅として数える計測を下限の判定に使うこと。
line の下限だけで、カバレッジの判定を済ませること。
カバレッジの数値を、テストの有効性が足りている証拠として扱うこと。

### 行動
coverlet.MTP を検証入口に組み、cobertura 出力を残す。
`branches-covered` と `branches-valid` から下限を判定し、割ったら止める。
未実行の箇所を読み、テストの取りこぼしを塞ぐ。
