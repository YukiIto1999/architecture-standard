## 効果を遅延した記述にして端で実行する

### 要求
副作用を伴う計算は、生成では実行されない遅延した記述として組み、実行を runtime の境界に限る。

### 根拠
記述は値なので、合成し、再試行し、差し替えても、その時点では副作用が起きない。
実行を境界に集めると、どこで副作用が起きるかが一箇所で読め、内側は副作用の起動を持たない。
生成と同時に実行する形は、合成も再試行も差し替えもできず、副作用がコード全体に散る。

### 完了条件
副作用を伴う計算が、生成では実行されない遅延した記述になっている。
記述の実行が、runtime の境界に限られている。
内側の層が、記述を実行していない。

### 禁止事項
生成と同時に副作用を起動する計算を、内側の層に置くこと。
記述の実行を、境界の外へ散らすこと。

### 行動
内側の層で生成と同時に副作用を起動している箇所を、洗い出す。
副作用を伴う計算を、遅延した記述として返し、合成する。
記述の実行を、入口の組立点に集める。

### 例

値を生成した時点で処理を実行すると、処理の合成も差し替えもできない。

```
const user = fetchUser(id)
```

処理を遅延した記述として構築し、境界の `run` でだけ実行する。

```
const program = fetchUser(id)
run(program)
```
