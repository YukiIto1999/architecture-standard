# caching

## 概要
caching は、正本から再構築できる短寿命の導出状態の鮮度・無効化・不在・障害時の意味を全系で統べる規律である。
principles の [data](../principles/data.md) が定める導出と控えの定めを、cache の扱いとして具象化する。
cache の規律の正本は、この file に置く。

## cache を正本の控えに保つ

### 要求
cache は正本の代わりにせず、cache-aside で読み書きし、各項目を期限で失効させて対象を特定して無効化する。
cache の項目の期限は、同一の固定値でなく、項目ごとに幅を持たせて与える。幅の値は project が定めて記録する。
正本に不在であることも、現存の項目より短い期限をつけた cache の項目として記録する。
HTTP の CDN と edge cache は応答の配送だけに使い、アプリケーションの状態または一時データの store にしない。

### 根拠
cache-aside と期限と対象別の無効化を固定すれば、cache の欠落を正本の欠落にせず、古い値の残存範囲を閉じられる。
cache の全項目へ同一の固定値の期限を与えると、配備や再起動で一斉に投入された項目が同じ時刻に失効し、その瞬間の読み取りが正本へ集中する。
不在を記録しなければ、正本に行を持たない鍵への問い合わせは cache を素通りし続け、cache が読み取りを吸収しない。
不在の期限を現存の項目より短くすれば、後からその行が作られたときに古い不在が残らない。
HTTP の配送 cache とアプリケーションの状態を分ければ、配信経路を正本や共有状態と誤認しない。

### 完了条件
cache の項目が期限で失効し、対象別に無効化され、不在の記録を持たない cache の欠落時に正本から取得されている。
cache の項目の期限が、同一の固定値でなく、項目ごとに幅を持って与えられ、幅の値が project の記録にある。
正本に不在の鍵が、現存の項目より短い期限をつけた不在の記録として cache されている。
CDN と edge cache が HTTP 応答の配送だけに使われ、アプリケーションの状態を保持していない。

### 禁止事項
cache を正本として扱うこと、期限または対象別の無効化を持たないこと。
cache の全項目へ同一の固定値の期限を与えること。
正本に不在の鍵への問い合わせを、cache を素通りさせて毎回正本へ到達させること。
CDN または edge cache を、アプリケーションの状態または一時データの store として使うこと。

### 行動
cache は cache-aside で配置し、項目の期限と対象別の無効化を定める。
cache の項目の期限の算出に幅を持たせ、同時に投入した項目の失効時刻が散ることを確かめる。
正本に不在であることを、現存の項目より短い期限の項目として記録する。
CDN と edge cache は HTTP 応答の配送だけに限定する。
