## 可変な正本の取得 cache の古さを期限と無効化で閉じる

### 要求
正本の現在の値を確かめずに、許容する古さの範囲で再利用する cache(取得 cache)は、結果が依存する可変な正本、許容する古さ、書き込みで無効化する対象を特定し、project が記録してから置く。
結果が依存する正本または無効化の対象を特定できない結果は、期限を付けても cache しない。
取得 cache は、正本の代わりにせず、cache-aside で読み書きし、各項目を期限で失効させて対象を特定して無効化する。
cache の項目の期限は、許容する古さを超えない範囲で、同一の固定値でなく、項目ごとに幅を持たせて与える。
幅の値は project が定めて記録する。
正本に不在であることも、現存の項目より短い期限をつけた cache の項目として記録する。
HTTP の CDN と edge cache は応答の配送だけに使い、アプリケーションの状態または一時データの store にしない。

### 根拠
取得 cache は正本の現在の値を確かめないので、保持した結果が正本と食い違う範囲は、依存する正本の特定、許容する古さ、書き込みでの無効化だけで閉じられる。
期限は古さの上限を与えるだけで、依存する正本と無効化の対象が不明な結果の妥当性を与えない。
cache-aside と期限と対象別の無効化を固定すれば、cache の欠落を正本の欠落にせず、古い値の残存範囲を閉じられる。
cache の全項目へ同一の固定値の期限を与えると、配備や再起動で一斉に投入された項目が同じ時刻に失効し、その瞬間の読み取りが正本へ集中する。
不在を記録しなければ、正本に行を持たない鍵への問い合わせは cache を素通りし続け、cache が読み取りを吸収しない。
不在の期限を現存の項目より短くすれば、後からその行が作られたときに古い不在が残らない。
HTTP の配送 cache とアプリケーションの状態を分ければ、配信経路を正本や共有状態と誤認しない。

### 完了条件
取得 cache の項目ごとに、依存する可変な正本、許容する古さ、書き込みで無効化する対象が、project の記録にある。
取得 cache の項目が期限で失効し、対象別に無効化され、不在の記録を持たない cache の欠落時に正本から取得されている。
取得 cache の項目の期限が、許容する古さを超えず、同一の固定値でなく、項目ごとに幅を持って与えられ、幅の値が project の記録にある。
失効または無効化した項目が再利用されず、次の取得が正本の結果で補われている。
正本に不在の鍵が、現存の項目より短い期限をつけた不在の記録として cache されている。
CDN と edge cache が HTTP 応答の配送だけに使われ、アプリケーションの状態を保持していない。

### 禁止事項
取得 cache を正本として扱うこと、期限または対象別の無効化を持たないこと。
依存する正本または無効化の対象を特定していない結果を、期限だけで cache すること。
取得 cache の全項目へ同一の固定値の期限を与えること。
正本に不在の鍵への問い合わせを、cache を素通りさせて毎回正本へ到達させること。
CDN または edge cache を、アプリケーションの状態または一時データの store として使うこと。

### 行動
取得 cache を置く前に、結果が依存する可変な正本、許容する古さ、書き込みで無効化する対象を特定して記録する。
特定できない結果は、依存を確定するまで cache しない。
取得 cache は cache-aside で配置し、項目の期限と対象別の無効化を定める。
取得 cache の項目の期限の算出に幅を持たせ、同時に投入した項目の失効時刻が散ることを確かめる。
正本に不在であることを、現存の項目より短い期限の項目として記録する。
CDN と edge cache は HTTP 応答の配送だけに限定する。
入力と依存の同一性を確かめて、古い結果を許さずに再利用する決定的な計算は、この規律の対象にせず、[deterministic-memo](./deterministic-memo.md) の「決定的な結果の再利用を依存の同一性で閉じる」に従う。
