## 観測は振る舞いを変えない

### 要求
観測は業務の振る舞いを変えず、観測の有無で業務の結果や順序が変わらないようにする。
観測の経路が無効でも業務は同じ結果と順序で動き、観測の呼び出しが業務を失敗させたり止めたりしない。

### 根拠
観測が業務の結果や順序を変えると、観測を入れたり外したりで挙動が揺れる。
観測を業務から独立に保てば、観測は安全に足し引きできる。
観測の経路を無効にしても業務が同じに動けば、観測の有無が結果に影響しない。
観測の出力を業務と切り離して非同期に流せば、出力先の不調が業務を止めない。

### 完了条件
観測の有無で、業務の結果や順序が変わらない。
観測の経路が無効でも、業務が同じ結果と順序で動く。
観測の呼び出しが、業務を失敗させたり止めたりしない。

### 禁止事項
観測のために、業務の結果や順序を変えること。
観測の出力の成否で、業務を失敗させたり止めたりすること。

### 行動
観測を業務の判断から切り離し、結果に影響しない位置で行う。

### 例

観測値を業務判断に使うと、観測が振る舞いを変える。

```
const count = counter.incrementAndGet(); if (count > limit) reject()
```

観測は記録だけに使い、業務の値から得た結果で判断する。

```
record(metric); if (decision.rejected) reject()
```
