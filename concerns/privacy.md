# privacy

## 概要
privacy は、個人情報の最小化と期限による消去を全系で統べる規律である。
principles の [data](../principles/data.md) が定める事実の保持と削除の判断を、個人情報を含む記録の扱いとして具象化する。
個人情報を含む記録は、載せる項目の絞り込みと保持の期限を備え、消去の義務を果たせる形に保つ。

## 個人情報は最小化して載せ、期限で消す

### 要求
記録する事実に個人情報を載せるときは、目的に必要な項目だけに絞る。
本人を特定できる項目は、必要がなければ載せず、必要なら仮名化するか識別子に置き換える。
個人情報を含む記録には保持の期限を定め、期限を過ぎた記録を消す。
消去の義務を負う個人データは個別に消せる形で保持し、管理操作で対象を消去する。
消去の監査には個人データを再記録せず、対象を識別できない消去済みの事実だけを残す。
バックアップには保持期限を定め、期限までに消去対象を含む世代を失効させる。

### 根拠
事実に文脈を豊かに載せる規律は、個人情報を無制限に運んでよい理由にはならない。
載せる項目を目的に必要な範囲へ絞れば、記録が漏れたときに及ぶ範囲を狭められる。
本人を特定できる形をそのまま残すと、記録そのものが個人情報の保管先になり、消去の義務を負う対象が記録の置き場にまで広がる。
仮名化や識別子への置き換えは、事後の相関を保ちながら本人の特定を難しくする。
保持の期限がない記録は、消去の義務を果たす手段を欠いたまま個人情報を溜め続ける。
管理操作とバックアップの期限を同じ消去義務へ結び付ければ、稼働中の正本だけを消して古い複製へ残す状態を防げる。

### 完了条件
記録する事実に含まれる個人情報が、目的に必要な項目だけに絞られている。
本人を特定できる項目が、仮名化されているか識別子に置き換えられているか、必要がなければ載っていない。
個人情報を含む記録に、保持の期限が定められている。
期限を過ぎた記録が、消えている。
消去対象の個人データが管理操作で個別に消去され、監査記録に再記録されていない。
消去対象を含むバックアップが、保持期限までに失効している。

### 禁止事項
目的に必要でない個人情報を、記録する事実に載せること。
個人情報を含む記録を、期限を定めずに保持し続けること。
消去した個人データを、消去の監査記録へ複製すること。
消去対象を含むバックアップを、定めた保持期限の後まで復元可能に保つこと。

### 行動
記録へ載せる項目を洗い出し、目的に必要な範囲を確認する。
本人を特定できる項目は、仮名化するか識別子に置き換える。
個人情報を含む記録に保持の期限を設定し、期限で消す仕組みを用意する。
個人データを個別に消去する管理操作を用意し、個人データを含まない消去済みの事実だけを監査へ残す。
バックアップの保持期限と失効を消去手順へ含める。
期限や義務による消去は、[data](../principles/data.md) の破壊的更新の定めに従い、失う情報が不要である根拠を project の決定記録に残す。

### 例

個人情報をそのままログへ載せると、漏えい時に本人を特定できる範囲が広がる。

```
log({ event: "order_placed", customerName, customerEmail, amount })
```

ログへ載せる情報を目的に必要な範囲へ絞り、本人を特定できる項目は識別子で扱う。

```
log({ event: "order_placed", customerId, amount })
```
