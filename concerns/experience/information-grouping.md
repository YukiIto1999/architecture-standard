## 情報を局面と依存でまとめ、余白と階層で導く

### 要求
情報は、利用の局面と前後の依存でまとめ、無関係なものを同列に混ぜない。
visual UI の視覚の区切りを、責務の境界に一致させる。
visual UI の構造は、罫線の多用でなく余白と字の強弱で示す。
無関係なものと稀にしか使わないものを、利用者面に出さない。

### 根拠
局面と依存でまとめると、利用者は今の局面に要るものだけを見られる。
visual UI で依存の向きをレイアウトで示すと、何が先で何が後かが分かる。
余分な情報は、関連する情報と競合して相対的な見やすさを下げる。
visual UI の装飾が主題を覆うと、データより様式が前に出る。

### 完了条件
情報が、利用の局面と依存でまとまっている。
visual UI の視覚の区切りが、責務の境界と一致している。
visual UI の構造が、罫線の多用でなく余白と字の強弱で示されている。
無関係なものと稀用のものが、利用者面に出ていない。

### 禁止事項
依存の異なる情報を、同列のフラットな並びに混ぜること。
visual UI の装飾で、データを覆うこと。
稀にしか使わない情報を、常時利用者面に出すこと。

### 行動
利用者面の情報を、利用の局面と依存で見分け、混在を解く。
visual UI では、依存の向きをレイアウトで表し、余白と強弱で階層を示す。
visual UI の装飾と、稀用の情報を削る。
