## 境界の外を既定で信頼しない

### 要求
境界の外から来るものを既定で信頼せず、信頼は境界での検証と認可を経た後にだけ与える。
検証の内容は [types](../types/parse-once-at-boundary.md) の「境界で一度だけ parse する」に従う。

### 根拠
外から来る値は、改竄や誤りを含みうる。
既定で信頼すると、不正な入力がそのまま内部を流れる。
境界で検証し認可を経たものだけを信頼すれば、内部は信頼できる値だけを扱う。

### 完了条件
境界の外から来る値が、検証と認可を経るまで信頼されていない。
信頼が、境界での検証と認可の後にだけ与えられている。

### 禁止事項
境界の外から来る値を、検証と認可を経ずに信頼すること。
境界の検証だけを、注入への唯一の防御にすること。

### 行動
外部入力を境界で検証して型へ通し、認可を経たものだけを内側へ渡す。
許す値を列挙して通し、危険な値の除外はそれを補う形にとどめる。
パラメータ化やエスケープのような出口側の防御も、境界の内の出力の直前で行う。
検証は [types](../types/README.md)、認可は [authorization](../authorization/README.md) に従う。

### 例

外部入力を検証せずに使うと、境界の外側から内部の処理を操作される。

```
database.query(request.body.filter)
```

境界で入力を検証して型へ変換し、認可を通過した値だけを内側へ渡す。

```
const query = parseQuery(request.body); authorize(actor, query); search(query)
```
