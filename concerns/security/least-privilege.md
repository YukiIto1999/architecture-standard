## 最小権限を与える

### 要求
各要素には必要な最小の権限だけを与え、権限の既定値を許可しないに置く。
既定の拒否は、framework の既定に頼らず明示する。
与えた権限は、定めた周期で見直して記録し、不要になった権限を回収する。

### 根拠
過剰な権限は、侵害されたときの被害を広げる。
必要な分だけに絞れば、被害が局所に収まる。
既定を拒否に置けば、許可は明示的に与えた分だけになる。

### 完了条件
各要素が、必要な最小の権限だけを持つ。
権限の既定値が、許可しないに置かれている。
既定の拒否が、framework の既定に依存せず明示されている。
与えた権限の見直しの周期が定められ、前回の見直しの記録があり、不要になった権限が回収されている。

### 禁止事項
必要を超える権限を、既定で与えること。

### 行動
要素ごとに必要な権限を洗い出し、それだけを与える。
権限の既定を拒否に置き、許可は明示的に与える。
権限の膨張を定期的に見直し、不要になった権限を回収する。

### 例

サービスへ広い権限を既定で与えない。

```
grant(service, ALL)
```

必要な操作だけを許可し、それ以外は既定で拒否する。

```
grant(service, [readOrders])
```
