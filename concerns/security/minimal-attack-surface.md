## 攻撃面を最小にする

### 要求
外部へ開く面を必要なものだけに絞り、使わない経路・機能・権限を開いたまま残さない。

### 根拠
開いた面は、すべて攻撃の入口になりうる。
使わない面を閉じれば、攻撃の入口が減る。
閉じるのは使わない面であって、要求された機能ではない。
要求された機能は作り切る。

### 完了条件
外部へ開く面が、必要なものだけに絞られている。
使わない経路・機能・権限が、開いたまま残っていない。

### 禁止事項
使わない経路・機能・権限を、開いたまま残すこと。

### 行動
公開する経路・機能・権限を棚卸しし、使わないものを閉じる。
新たに開く面ごとに、必要性を確かめる。

### 例

使用しない管理用経路を公開したままにすると、攻撃できる面が増える。

```
expose(["/api", "/admin", "/debug"])
```

必要な経路だけを公開し、管理用経路とデバッグ用経路は閉じる。

```
expose(["/api"])
```
