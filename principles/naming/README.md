# naming

naming は、命名と語彙に関する原則を置く。
名前で意味を表し、業務の語彙を統一する。
識別子は英語で書き、役割と具体で名付ける。
汎用名と略語を制限し、種類ごとに名付ける。
参照範囲で名前の可変性を見積もり、最初の命名を丁寧にして乱れを早期に直し、テスト名で仕様を表す。
casing と接辞の形式の規約は言語ごとに異なるため、[tools](../tools/) に置く。
